# Baseline tour packs

- **Pack A** — five short single-floor runs. Each has two complete laps: all object changes on lap 1, confirmation on lap 2.
- **Pack B** — five different single-floor runs. Each has three complete laps: object changes across laps 1 and 2, confirmation on lap 3.
- **Pack C** — five planned multi-floor runs. Multi-floor execution still requires its separate certification gate.

Every pack includes an overview PNG, five per-scene PNGs, portable schedules and navmeshes, compiled dynamic scripts, expected object-change records, coverage grids, native semantic ground truth, validation metadata, and SHA-256 manifests. Coverage uses the full collision-supported non-obstacle floor domain rather than a navmesh-only denominator. Dynamic changes are expected inputs; recorded outcomes must come from execution evidence.
